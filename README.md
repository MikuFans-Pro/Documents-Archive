# 个人文章存档

这个仓库用于存储我（Victor_Jay / 兰纳西妲）在多个平台发布的原创技术文章，涉及 Flarum 社区搭建、CDN 本地化、PHP 开发等主题。

## 为什么建这个仓库

- **防止数据丢失**：文章首发于各平台，集中备份一份到 Git 最稳妥
- **版权归属**：明确原创出处，应对未来可能的转载或侵权问题
- **时间戳佐证**：[Web Archive 快照列表](internet-archive-snapshots.txt)，第三方独立记录的发布时间，版权纠纷时有据可查
- **便于归档**：系列文章按编号整理，一目了然
